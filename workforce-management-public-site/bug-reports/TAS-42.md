# Social Media Icons (X, LinkedIn, GitHub) Open Email Composer Instead of Their Respective Social Media Pages

**Severity:** Medium
**Priority:** Medium

## Description
In the workforce management platform website footer, the social media icons (X, LinkedIn, and GitHub) do not navigate to their respective official social media pages. Instead, clicking any of them opens the default email client with a new email addressed to [company sales email].

## Steps to Reproduce
1. Navigate to the workforce management platform website
2. Scroll to the footer
3. Click the X icon
4. Observe the action
5. Repeat the same steps for the LinkedIn and GitHub icons

## Actual Result
Clicking the X, LinkedIn, or GitHub icon opens the default email client with a new email addressed to [company sales email], instead of navigating to the respective social media page.

## Expected Result
Each social media icon should open its corresponding official social media page (X, LinkedIn, or GitHub) in a new browser tab.

## Environment
* Platform: Web
* Browser: Microsoft Edge
* OS: Windows 11
* Page section: Footer — Social media icons
