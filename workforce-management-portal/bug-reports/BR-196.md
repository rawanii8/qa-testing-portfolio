# Meeting pre-join screen displays a corrupted mixed-language string ("والميكrofon") instead of the correctly localized Arabic word for "microphone".

**Severity:** Low
**Priority:** Medium
**Status:** new

## Description
On the Meetings (الاجتماعات) pre-join screen, the instructional text displayed beneath the "جاهز للانضمام" (Ready to Join) heading contains a corrupted localization string.

Instead of displaying the Arabic word "الميكروفون", the application renders a mixed-language text "والميكrofon", combining Arabic characters with an incomplete English/phonetic fragment. This results in an obvious localization defect and an unprofessional user experience.

## Steps to Reproduce
1. Log in to the workforce management platform portal.
2. Set the application language to Arabic.
3. Navigate to Communication (التواصل).
4. Open or join any meeting.
5. Observe the instructional text displayed on the meeting pre-join screen.

## Actual Result
The helper text displays:

> "...اسمح بالكاميرا والميكrofon للانضمام الأسرع."

## Expected Result
The helper text should display a fully localized Arabic sentence, for example:

> "...اسمح بالكاميرا والميكروفون للانضمام بشكل أسرع."
