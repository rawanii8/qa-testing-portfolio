# Manager editing leave request reason overwrites and permanently removes employee’s original reason

**Severity:** High
**Priority:** High
**Status:** Done

## Description
In the Leave Management (إدارة الإجازات) module, when a manager edits an employee’s leave request, the original reason provided by the employee is permanently overwritten. After saving the manager’s changes, only the updated text remains stored, and the original employee submission is no longer accessible.

This behavior results in loss of original user-provided data and eliminates any ability to track what was initially submitted.

## Steps to Reproduce
1. Log in as an Employee
2. Submit a leave request with a specific reason in the Leave module
3. Log out and log in as a Manager
4. Navigate to Leave Management (إدارة الإجازات)
5. Open the employee’s leave request
6. Edit the reason field and save changes
7. Log out and log back in as the Employee
8. Open the same leave request

## Actual Result
- Manager can edit the employee’s original leave reason
- After saving, the employee’s original reason is fully replaced
- No trace of the original submitted reason remains
- No audit history or versioning is available

## Expected Result
- Employee’s original leave reason should remain unchanged and preserved
- Manager edits should be stored separately (e.g., “Manager’s Note”)
- Alternatively, a full edit history should be maintained
- Original and modified content should both remain accessible for audit purposes

## Environment
- Browser: Google Chrome
- OS: Windows 11
- Device: Desktop
