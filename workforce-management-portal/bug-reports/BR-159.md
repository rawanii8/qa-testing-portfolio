# Task status column (الحالة) displays raw backend enum values (in_progress, done) instead of translated Arabic labels in the My Tasks page (مهامي)

**Severity:** Medium
**Priority:** Medium
**Status:** new

## Description
In the My Tasks page (مهامي) on the workforce management platform, the الحالة (Status) column in the task list table displays raw backend enum values such as "in_progress" and "done" instead of human-readable Arabic labels. All other column headers and surrounding page content are in Arabic — ساعات فعلية, ساعات تقديرية, تاريخ الاستحقاق, العنوان, الأولوية — but the status value itself is rendered as the raw internal code used by the system, not a translated display label. This indicates the status field is not being mapped through the localization/display layer before being rendered in the UI.

## Steps to Reproduce
1. Log in to the internal web portal as an institutional admin (مسؤول مؤسسة)
2. Navigate to مهامي from the left sidebar under التنفيذ والتعاون
3. View the task list in قائمة (List) view
4. Observe the الحالة column for each task row

## Actual Result
- The الحالة column displays raw enum values: "in_progress", "done"
- These are untranslated backend code values, not localized display labels
- The values are also in English while every other column and label on the page is in Arabic

## Expected Result
- The status should be displayed using its mapped Arabic label: in_progress → قيد التنفيذ, done → مكتملة
- All status values across the task list should be fully localized and consistent with the rest of the Arabic interface

## Environment
- Browser: Chrome
- OS: Windows 11
- Device: Desktop
