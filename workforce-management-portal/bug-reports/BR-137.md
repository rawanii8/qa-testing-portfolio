# “Cancel all sessions” logs out current active session instead of terminating only other sessions

**Severity:** High
**Priority:** High
**Status:** Done

## Description
In the Profile Settings (الإعدادات) page, the “Cancel all sessions” (إلغاء كافة الجلسات) feature incorrectly terminates the user’s current active session along with all other sessions.

Instead of selectively invalidating secondary sessions across devices, the system performs a full session invalidation, immediately logging the user out of the current device and redirecting them to the login page.

This behavior breaks expected session management logic and disrupts user workflow.

## Steps to Reproduce
1. Navigate to Profile & Settings (الملف الشخصي والإعدادات)
2. Open the Active Sessions (الجلسات النشطة) tab
3. Click “إلغاء كافة الجلسات” (Cancel all sessions)
4. Confirm the action in the modal dialog

## Actual Result
- All sessions, including the current one, are terminated
- User is immediately logged out
- User is redirected to the login page (`/login`)
- No opportunity is provided to continue the current session

## Expected Result
- Only other active sessions (different devices/browsers) should be terminated
- The current session should remain active
- User should stay logged in and receive a success confirmation message

## Environment
Browser: Edge/Chrome
OS: Windows 11
Device: Desktop
