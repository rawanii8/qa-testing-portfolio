# Selecting Custom date range in Team Reports crashes the page with React error 185

**Severity:** Critical
**Priority:** High
**Status:** to verify

## Description
In the Team Reports (تقارير الفريق) page, when the user selects the Custom (مخصص) date range option and then clicks the calendar icon, the entire page crashes and displays a fatal error screen — "حدث خطأ ما" — with the error message "Minified React error 185". The user is unable to use the custom date range feature at all and must navigate away from the page to recover.

## Steps to Reproduce
1. Log in as a Manager
2. Navigate to Team Reports
3. Click on the date range filter
4. Select Custom (مخصص) option
5. Click on the calendar icon
6. Observe the result

## Actual Result
- The page crashes completely and displays the error screen "حدث خطأ ما"
- The error message reads: "Minified React error 185"
- The user is forced to either click "فتح لوحة التحكم" or "الصفحة الرئيسية" to recover
- The custom date range feature is completely non-functional

## Expected Result
- Clicking the calendar icon after selecting Custom should open a date picker allowing the user to select a start and end date
- No crash or error should occur under any circumstances
- The page should remain stable and functional throughout the date selection process

## Environment
- Browser: Google Chrome
- OS: Windows 11
- Device: Desktop
