# Main content area becomes blank/hidden during navigation in Reports module

**Severity:** Critical
**Priority:** High
**Status:** Done

## Description
In the Monitoring & Reports (المراقبة والتقارير) module, the main content area intermittently fails to render during navigation and filter interactions. While the sidebar and top navigation remain visible and functional, the central content section (tables, charts, and report data) becomes completely blank or hidden.

## Steps to Reproduce
1. Log in to the workforce management platform portal
2. Navigate to Monitoring & Reports (المراقبة والتقارير) → My Reports (تقاريري)
3. Open any available report view
4. Apply filters (e.g., date range or status) or switch between report tabs
5. Observe the main content area after interaction

## Actual Result
- Main content area becomes blank or disappears completely
- Sidebar and top navigation remain visible
- No fallback UI (loading skeleton or error message) is shown
- Report data (tables/graphs) is not rendered

## Expected Result
- Main content area should always remain structurally stable
- If data is loading, a proper loading state should be displayed
- If an error occurs, a user-friendly error message should appear
- Navigation and layout should not break or hide core content

## Environment
Browser: Chrome
OS: Windows 11
Device: Desktop
