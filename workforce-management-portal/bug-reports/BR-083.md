# Work session timer resets to zero every 60 seconds during active tracking

**Severity:** High
**Priority:** High
**Status:** Done

## Description
In the Human Resources & Attendance (الموارد البشرية والحضور) module under the Today (اليوم) work session view, the Work Hours (ساعات العمل) timer incorrectly resets after reaching 00:01:00 instead of continuing to increment normally.

This behavior breaks the core time-tracking logic of the system. Instead of accumulating elapsed time, the timer repeatedly restarts, leading to inaccurate session duration tracking and unreliable attendance records.

## Steps to Reproduce
1. Log in to the workforce management platform portal
2. Navigate to Human Resources & Attendance (الموارد البشرية والحضور) → Today (اليوم)
3. Click Clock In (تسجيل حضور) to start a work session
4. Observe the running Work Hours (ساعات العمل) timer
5. Wait until the timer reaches 00:01:00

## Actual Result
- Timer resets to 00:00:00 every 60 seconds
- Elapsed work time is not accumulated
- Session duration appears incorrect or unstable
- No user action triggers the reset

## Expected Result
- Timer should continuously increment (00:01:01, 00:01:02, etc.)
- Work session duration should accumulate accurately
- Reset should only occur on explicit user actions (Clock Out / Reset)
- Attendance data should reflect correct total time

## Environment
Browser: Chrome
OS: Windows 11
Device: Desktop
