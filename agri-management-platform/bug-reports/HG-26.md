# [Web] Name field rejects valid Arabic names, incorrectly showing "must contain letters and spaces only" validation error

**Severity:** High
**Priority:** High

## Description
On the Register form, entering a valid Arabic name consisting only of Arabic letters (e.g., "روان") triggers the validation error "يجب أن يحتوي الاسم على أحرف ومسافات فقط" (The name must contain letters and spaces only), even though the entered text does in fact contain only letters and no invalid characters. This strongly suggests the field's validation regex only accepts Latin/English letters (e.g., a-zA-Z) and does not include the Arabic Unicode character range, making it impossible for Arabic-speaking users to register with their name written in Arabic — a critical usability blocker on an Arabic-first site.

## Steps to Reproduce
1. Navigate to: [the agricultural management platform staging URL]
2. Ensure the site language is set to Arabic
3. Click into the "الاسم" (Name) field
4. Type a valid Arabic name using only letters and spaces (e.g., "روان")
5. Observe the validation message that appears

## Actual Result
The field rejects the valid Arabic name and displays: "يجب أن يحتوي الاسم على أحرف ومسافات فقط", incorrectly implying the input contains invalid characters when it does not.

## Expected Result
The Name field's validation should accept Arabic letters (in addition to Latin letters, if English names are also supported) and spaces, and should not reject valid Arabic input. This is especially critical since the site's primary/default language is Arabic.

## Environment
* URL: [the agricultural management platform staging URL] 
* Browser: Microsoft Edge
* Language: Arabic (RTL)
* Field: الاسم (Name) — Register form
