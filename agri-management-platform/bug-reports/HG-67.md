# [Web] Authentication pages intermittently crash with "Out of Memory" error during normal user interaction

**Severity:** High
**Priority:** Highest

## Description
While testing the Authentication module, the browser tab intermittently crashes and displays an *"Out of Memory"* error during normal user interaction. The issue has been reproduced multiple times on different browsers without performing any abnormal or resource-intensive actions.

The crash terminates the current page, preventing users from continuing authentication-related tasks such as signing in, registering, or recovering their account. Since the issue was reproduced in multiple browsers, it may indicate excessive client-side memory consumption or a potential memory leak within the Authentication module.

h3.

## Steps to Reproduce
1. Navigate to the agricultural management platform Authentication module.
2. Interact with the authentication pages under normal usage (e.g., navigate between authentication screens, switch languages, or fill forms).
3. Continue testing the authentication workflow.
4. Observe the browser behavior.
5. h3.

## Actual Result
The browser tab unexpectedly crashes and displays an *Out of Memory* error.

Examples include:

* *Microsoft Edge:* _"This page is having a problem"_ – *Error code: Out of Memory*
* *Google Chrome:* _"Aw, Snap!"_ – *Error code: Out of Memory*

The current page becomes unavailable, forcing the user to reload the page and potentially lose any entered data.

h3.

## Expected Result
Authentication pages should remain stable throughout normal user interaction without exhausting browser memory or causing the browser tab to crash. Users should be able to complete authentication-related tasks without interruption.

h3.

## Environment
* *Module:* Authentication
* *Browsers:*
** Microsoft Edge
** Google Chrome
* *Operating System:* Windows
