# [Mobile]  [Mobile] Analysis percentages are suspiciously uniform (equally divided) across Vegetation, Water Content, and Salinity tabs

**Severity:** Medium
**Priority:** Medium

## Description
On the Field Details screen, under "التحليل الزراعي" (Agricultural Analysis), the percentage breakdown displayed in the Vegetation Cover (الغطاء النباتي), Water Content (محتوى الماء), and Salinity (الملوحة) tabs shows values that are always perfectly and equally divided across the number of categories, rather than reflecting realistic, independently calculated satellite analysis data. This pattern is consistent with the previously reported issue of identical min/max temperature values, suggesting a broader data mapping/fallback problem across multiple analysis metrics.

## Steps to Reproduce
1. Navigate to a Farm > select a Field (e.g., "حقل تلقائي 3")
2. Open "التحليل الزراعي" (Agricultural Analysis)
3. Check the percentage breakdown under each of the following tabs: "الغطاء النباتي" (Vegetation Cover), "محتوى الماء" (Water Content), "الملوحة" (Salinity)

## Actual Result
* Vegetation Cover tab: 3 categories, each showing exactly 33.3%
* Water Content tab: 4 categories, each showing exactly 25.0%
* Salinity tab: 5 categories, each showing exactly 20.0%

## Expected Result
Each analysis tab should display percentages that reflect the actual calculated distribution of the corresponding satellite/field data, which would realistically vary between categories rather than being perfectly equal (100 ÷ number of categories) in every case.

## Environment
App: the agricultural management platform (Mobile App)
Device: iPhone 13
OS: iOS|Andriod
