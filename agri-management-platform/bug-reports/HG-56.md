# [Web] Phone-based Sign-In fails with "Either email or phone number must be provided" despite phone number being entered correctly

**Severity:** High
**Priority:** Highest

## Description
On the Sign-In page (phone-based login mode), entering a valid, correctly-formatted phone number (matching the one used during registration) and a valid password, then submitting the form, results in a login failure with the message "Either email or phone number must be provided" — even though the phone number field is clearly filled in. This suggests the phone number value may not be getting correctly read/passed to the backend authentication request (e.g., a field name mismatch, or the phone value not being included in the submitted payload), causing the server to treat the request as if no identifier was provided at all. This fully blocks users from signing in via phone number, even with correct credentials.

## Steps to Reproduce
1. Navigate to: [the agricultural management platform staging URL]
2. Ensure the site language is set to Arabic
3. Click the phone icon under "أو سجل الدخول باستخدام" to switch to phone-based login
4. Enter a valid, previously registered phone number (e.g., "+20 010 692 643 49")
5. Enter the correct password for that account
6. Click "تسجيل الدخول" (Sign In)
7. Observe the error message displayed

## Actual Result
Two error messages appear: "Login failed" and "Either email or phone number must be provided", despite the phone number field containing a valid, correctly-formatted number.

## Expected Result
If the phone number and password are correct, the login should succeed. If there is a genuine validation issue, the error message should accurately reflect the actual problem rather than incorrectly claiming the field is empty when it is not.

## Environment
* URL: [the agricultural management platform staging URL] 
* Browser: Microsoft Edge
* Language: Arabic (RTL)
* Field/Action: Sign-In via Phone Number with previously registered credentials
