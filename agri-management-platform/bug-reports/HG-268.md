# [Mobile] Country codes displayed in English numerals inside Country Code picker, inconsistent with Arabic numerals shown in the field

**Severity:** Medium
**Priority:** Medium

## Description
On the Edit Profile screen, while the app is set to Arabic, the country code displayed in the phone number field itself uses Arabic-Indic numerals (e.g., "+٢٠" for Egypt). However, when opening the country code picker/list to select a different country, all country codes inside the list are displayed using English numerals (e.g., "1264+", "998+", "256+"), creating an inconsistency between the field and the picker.

## Steps to Reproduce
1. Set app language to Arabic
2. Navigate to Profile > Edit Profile (تعديل الملف الشخصي)
3. Note the country code shown in the phone number field (Arabic numerals)
4. Tap to open the country code picker/list
5. Observe the numerals used for each country's code inside the list

## Actual Result
The country code field displays Arabic-Indic numerals (e.g., "+٢٠"), but the country code picker list displays the same information using English numerals (e.g., "1264+", "998+").

## Expected Result
Country codes should be displayed consistently using Arabic-Indic numerals both in the phone field and inside the country code picker list.

## Environment
App: the agricultural management platform (Mobile App)
Device: iPhone 13
OS: iOS | Andriod
