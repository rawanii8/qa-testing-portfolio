# [Mobile] Missing validation allows self-intersecting farm boundary polygon to be drawn and saved

**Severity:** High
**Priority:** High

## Description
When drawing a farm boundary on the "Add New Farm" (إضافة مزرعة جديدة) map screen, the app allows the user to place boundary points in an order that creates a self-intersecting polygon (crossing lines), with no validation warning at any stage. The invalid shape can be saved successfully with no error message, which will likely cause incorrect area calculations and downstream data issues for any features relying on the farm's boundary geometry.

## Steps to Reproduce
1. Navigate to Add New Farm (إضافة مزرعة جديدة)
2. Draw a farm boundary by placing points on the map in an order that causes the connecting lines to cross each other (self-intersecting polygon)
3. Proceed to save/continue with the form

## Actual Result
* No validation warning appears while drawing the self-intersecting shape
* The invalid boundary is saved successfully with no error message

## Expected Result
The app should validate the polygon shape and prevent saving (or at least warn the user) when the drawn boundary is self-intersecting, since this does not represent a valid, real-world field/farm shape.

## Environment
App: the agricultural management platform (Mobile App)
Device: iPhone 13
OS: ios|Andriod
