## Categories Covered

- **Localization / RTL** — untranslated strings, English numerals instead of Arabic-Indic numerals, mistranslated terms, reversed text/number order in RTL layout
- **Functional** — broken validation, non-functional buttons, failed sign-in flows, data not saving/displaying correctly
- **Data integrity** — inconsistent values between screens (e.g., field area totals), suspicious/duplicated data
- **Security-Related Validation** — internal debug data and technical error messages exposed directly to end users
- **UI/UX** — layout, alignment, and visual consistency issues
