# [Mobile] UI Bug: Selected Bottom Navigation Item Has Insufficient Visual Emphasis

**Severity:** Low
**Priority:** Low

## Description
The selected navigation item in the bottom navigation bar has insufficient visual emphasis. The highlight color of the selected icon and label is too light, making it difficult for users to distinguish the active tab from the inactive ones. This reduces the visibility of the current navigation state and may impact usability.

## Preconditions
The user is logged into the application.
The application is displaying the bottom navigation bar.
Any tab in the bottom navigation is selected (e.g., Tasks (المهام)).

## Steps to Reproduce
1. Launch the application.
2. Navigate to any screen with the bottom navigation bar.
3. Tap on the Tasks (المهام) tab (or any other tab).
4. Observe the visual appearance of the selected navigation item.

## Actual Result
The selected navigation item's highlight is too light, making the active tab difficult to identify at a glance.

## Expected Result
The selected navigation item should have a clear and prominent highlight that makes it easily distinguishable from the unselected items, following the application's design guidelines.
