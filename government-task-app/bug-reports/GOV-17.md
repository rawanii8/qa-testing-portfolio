# [Mobile] UI Bug: Reload/Refresh Icon Shows No Visual Feedback When Tapped

**Severity:** Low
**Priority:** Low

## Description
The Reload/Refresh icon in the top app bar does not display any visual feedback when it is tapped or becomes active. Unlike the other action icons, which indicate their active state through a highlighted background, the reload icon remains unchanged, making it difficult for users to recognize that the action has been triggered.

## Preconditions
The user is logged into the application.
The Daily Tasks (مهامي اليومية) screen is open.
The Reload/Refresh action is available.

## Steps to Reproduce
1. Launch the application.
2. Navigate to the Daily Tasks (مهامي اليومية) screen.
3. Tap the Reload/Refresh icon in the top app bar.
4. Observe the icon's appearance after the interaction.

## Actual Result
The Reload/Refresh icon does not display any active highlight or visual feedback after interaction, making its state inconsistent with the other app bar icons.

## Expected Result
The Reload/Refresh icon should display a clear active/highlighted state that is consistent with the behavior and design of the other action icons in the top app bar.
