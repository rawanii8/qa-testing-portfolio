# [Mobile] UI Bug: Download/Sync Icon Shows Unwanted Circular Background and Shadow in Active State

**Severity:** Low
**Priority:** Low

## Description
The Download/Sync icon in the top app bar displays an unwanted circular background and shadow effect when it is in the active state. This visual artifact is inconsistent with the styling of the other action icons in the app bar and creates an unpolished user interface.

## Preconditions
The user is logged into the application.
The Daily Tasks (مهامي اليومية) screen is open.
The Download/Sync action is in its active/highlighted state.

## Steps to Reproduce
1. Launch the application.
2. Navigate to the Daily Tasks (مهامي اليومية) screen.
3. Observe the Download/Sync icon in the top app bar when it becomes active.
4. Compare its appearance with the other app bar icons.

## Actual Result
The active Download/Sync icon is displayed with an unwanted circular background and shadow overlay, making it visually inconsistent with the other icons in the top app bar.

## Expected Result
The active icon should follow the application's design system and display without any unnecessary circular background or shadow. Its appearance should be consistent with the other top app bar icons.
